## Reporting a Vulnerability

AuraTools Studios takes the security of our platforms and user data seriously. If you discover a vulnerability or security risk across any ATS product or endpoint:

1. **Do not create a public issue** disclosing vulnerability details.
2. Please report findings directly via email to: **aggarwal.2022013@outlook.com**.
3. Include clear steps to reproduce, affected endpoints, and potential impact.
4. We aim to acknowledge receipt within 48 hours and coordinate remediation before public release.
