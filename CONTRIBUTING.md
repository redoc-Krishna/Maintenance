# Contributing to AuraTools Studios

Thank you for your interest in contributing to the **AuraTools Studios** ecosystem!

## How You Can Contribute

As this repository hosts the public specifications, documentation, and issue tracker:
- **Bug Reports & Feedback**: Open an issue detailing unexpected behavior, UI glitches, or broken links with reproduction steps and browser details.
- **Feature Requests**: Suggest new tools, integrations, or workflow enhancements via GitHub Discussions or Issues.
- **Documentation**: Propose improvements to READMEs, architecture guides, or API specifications via pull requests.

## Code of Conduct

Please maintain a respectful, constructive, and inclusive environment across all discussions and pull requests.
